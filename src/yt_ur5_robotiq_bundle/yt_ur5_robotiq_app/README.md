# ur — pick_and_place application bundle

Generated by the **TrainIt Setup Assistant**. Runs on the **TrainIt Motion Runtime**
(`trainit_motion_runtime`) as a Behaviour Tree. One command brings up the cell; a
second runs the application — in `mock`, `isaac`, or `real`.

## Packages in this bundle
| Package | Role |
|---|---|
| `yt_ur5_robotiq_app` | The application: BT (`bt_trees/pick_place.xml`) + `config/bt_params.yaml` (every DOF) + launch. |
| `yt_ur5_robotiq_trainit_config` | Self-contained scene+planner MoveIt config (mock/isaac/real bring-up + OMPL/Pilz/CHOMP + the scene loader). |
| `yt_ur5_robotiq_description` | Robot geometry viewer (entry-level: see the robot + EE in RViz). |

## Build
```bash
cd <your_ros2_ws>
colcon build --packages-up-to yt_ur5_robotiq_app
source install/setup.bash
```

## Run
Two terminals (both sourced).

**1 — bring up the cell** (move_group + planners + scene + controllers/bridges + RViz):
```bash
ros2 launch yt_ur5_robotiq_trainit_config bringup.launch.py mode:=gazebo
```
- `mode:=isaac` — first open Isaac Sim, load the cell USD, press **Play**, then launch.
- `mode:=mock` — pure ROS 2 controllers, no simulator.
- `mode:=real` — the vendor bridges drive the physical robot (no simulator, no ros2_control).

**2 — run the application** (the Behaviour Tree):
```bash
ros2 launch yt_ur5_robotiq_app trainit_bt.launch.py planner_mode:=ompl
```
`planner_mode` ∈ `pilz | ompl | ompl_chomp`. Watch it live in Groot2 (port 1667).

## Where to tune the application (the degrees of freedom)
| What | File |
|---|---|
| Waypoint poses / joints, motion type, planner, speed, start tolerance | `yt_ur5_robotiq_app/config/bt_params.yaml` (`task_parameters:`) |
| The sequence / tool actions (grasp, release, per-move flags) | `yt_ur5_robotiq_app/bt_trees/pick_place.xml` |
| Scene obstacles + dynamic-object flags (attach, collision, freeze/gravity) | `yt_ur5_robotiq_trainit_config/config/scene.yaml` |
| Planner limits (velocity/accel, cartesian) | `yt_ur5_robotiq_trainit_config/config/joint_limits.yaml`, `pilz_cartesian_limits.yaml` |

## Dynamic objects (Isaac)
The BT toggles two things automatically during the cycle:
- **`SetAttachedCollisionCheck`** — when the gripper holds objects, ON makes the planner
  route the held payload around the static meshes (e.g. into the prewash); OFF makes it
  transparent (e.g. at the pick, on the belt).
- **`SetReleasePolicy`** (`freeze` | `gravity`) — what a released object does in Isaac.

> The Isaac-side grasp **physics** (fixed-joint attach vs SurfaceGripper) is NOT part of
> this bundle — it lives hand-authored in the cell's **`*_isaac`** package (the Script
> Node that reads `/isaac_gripper_cmd` and `/isaac_release_policy`). See that package.
